# EPUB Exporter — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning something and fixing something are different needs, so they live on different pages. Only the kinds that have content are listed here.

**New here?** → [Getting started](getting-started.md) — from the install to your first EPUB.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the exact message you see, what it means, what to do.

| | |
|---|---|
| **[Getting started](getting-started.md)** | Learning-oriented. Turn a note with embedded chapters into a book and export it. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "This note is not a book note", "Nothing to export", "chapters could not be found", and the cover messages. |

The [README](https://github.com/johannes-kaindl/epub-exporter/blob/main/README.md) covers what the plugin does, the book model, every way into an export and every setting.
